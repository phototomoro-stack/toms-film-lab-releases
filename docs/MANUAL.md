# Tom's Film Lab 操作マニュアル

対象バージョン: **v0.2.7.1**（macOS）

フィルムネガをポジに反転し、仕上げて書き出すための現像アプリです。
このマニュアルは画面の並び順（読み込み → プレビュー → 調整パネル → 書き出し）に沿って構成しています。

## 1. はじめに（基本の流れ）

1. **ネガを読み込む** — スキャン画像をドラッグ＆ドロップ、または `⌘O`
2. **反転して調整する** — 読み込み時に自動でポジへ反転。ベース色を合わせてから露出・カラーを整える
3. **プリセットで仕上げる** — 右パネルからワンクリックで適用、気に入ったら自分のプリセットとして保存
4. **書き出す** — `⌘E` で1枚、`⌘⇧E` でロール一括

この4ステップは、アプリ内のチュートリアル（ツールバーの **？** ボタン、またはメニュー **ヘルプ ▸ チュートリアル…**）からいつでも見返せます。

## 2. 画像を読み込む

### 対応形式

| 種類 | 拡張子 |
|---|---|
| 一般画像 | `.jpg` / `.jpeg`, `.png`, `.tif` / `.tiff` |
| RAW | `.dng`, `.cr2`, `.cr3`, `.nef`, `.nrw`, `.arw`, `.sr2`, `.srf`, `.raf`, `.rw2`, `.orf`, `.pef`, `.ptx`, `.srw`, `.x3f`, `.mrw`, `.rwl`, `.iiq` |

### 読み込み方法

- **ドラッグ＆ドロップ** — ウインドウに画像やフォルダを落とす
- **メニュー** — ファイル ▸ 開く…（`⌘O`）
- **フィルムストリップ下部の「画像を追加」ボタン**

フォルダを選ぶと、その中の対応ファイルがまとめて「ロール」として読み込まれます。

読み込んだ時点で自動的にネガ反転が適用されます。設定の **色補正の初期モード** によって、
オレンジマスク除去まで自動で行うかどうかが変わります（→ [11. 設定](#11-設定)）。

## 3. 画面の構成

```
┌──────────────────────────────────────────────────────┐
│ ツールバー（開く / 取り消す / やり直す / ？ など）        │
├────────────┬───────────────────────────┬─────────────┤
│            │                           │             │
│ フィルム    │        プレビュー          │  調整パネル  │
│ ストリップ  │   （ズーム・トリミング）     │  + プリセット│
│            │                           │             │
└────────────┴───────────────────────────┴─────────────┘
```

- **フィルムストリップ**（左） — ロール内の全画像。クリックで切り替え、複数選択も可能
- **プレビュー**（中央） — 現像結果の表示。下部にズーム・回転・反転・Before/After・トリミングのツールバー
- **調整パネル**（右） — セクションごとの調整項目。並べ替え可能
- **プリセットパネル**（右端） — 内蔵／自作プリセットの一覧。折りたたみ可能

---

## 4. プレビューの操作

| 操作 | 方法 |
|---|---|
| 拡大・縮小 | トラックパッドのピンチ、またはツールバーの ＋ / − |
| 移動（パン） | 拡大中にドラッグ |
| 画面に合わせる | ツールバーのフィットボタン、または `⌘0` |
| 100%（フィット）に戻す | ツールバー中央のリセットボタン |
| 90° 回転 | `[` / `]`、またはツールバーの回転ボタン |
| 水平・垂直反転 | ツールバーの反転ボタン（ショートカットは既定で未割り当て） |
| Before/After 比較 | `\`、またはツールバーの「編集前後」ボタン |

ズームの効き具合は設定の **プレビュー操作 ▸ ズーム感度** で調整できます。

### スポイト（カラーピッカー）

ベース色やホワイトバランスのスポイトを起動すると、カーソル位置を拡大表示する**ルーペ**が出ます。
実際の画像ピクセルを拡大しているので、狙った1点を正確に選べます。`Esc` またはバナーの「キャンセル」で終了します。

## 5. トリミング・傾き補正

`R` キー、またはプレビュー下部の **トリミング** ボタンで開始します。

- **枠のドラッグ** — 四隅・各辺のハンドルでサイズ変更、内側をドラッグで移動
- **比率** — Free / 1:1 / 4:3 / 3:2 / 16:9 / 9:16。Free でも `⇧` を押しながらハンドルを引くとその時点の比率を保持、`⌥` で中央基準
- **縦横反転** — 比率固定中に向きを入れ替え
- **傾き補正** — `−1°` `−0.1°` `+0.1°` `+1°` の微調整ボタンと、90° 回転
- **フィルム判モード** — 35mm / 6×6 / 645 / 6×7 / 判指定なし。選ぶと現在の枠がその比率にスナップします
- **自動** — 像の範囲を自動検出してトリミング枠を提案します。結果は手で微調整できます
  （傾いたスキャンや、縁のコントラストが淡いスキャンでは検出できないことがあります）

トリミングは書き出しにも反映されます。解除したいときはツールバーの **クロップをリセット** を使います。

## 6. 調整パネル

各セクションの見出し右にある **?** ボタンで、そのセクションの説明が読めます。
セクションの並び順は **並べ替え** から変更でき、**デフォルト順** で戻せます。

### 6.1 ネガ反転（Negative Inversion）

ポジ化の土台となるセクションです。

| 項目 | 内容 |
|---|---|
| Invert Negative | ネガ反転のオン／オフ |
| Orange Mask | オレンジマスクの除去量（0〜2.00） |
| 色補正 | **オート** / **マニュアル** の切り替え |

**オート**では **自動** ボタンを押したときに、フィルムのベース色を推定 → オレンジマスク除去 →
白がニュートラルになるようホワイトバランス調整、までを一度に行います。

**マニュアル**では **ベース色** のスポイトで、ネガのフィルム縁（未露光部分）をクリックします。
ベース色を取得した時点で色補正が効きはじめます。× ボタンで解除すると自動推定に戻ります。

> **ヒント** ベース色は、コマの外側にある「素通しのフィルムの色」を選ぶのが正解です。
> 暗すぎる場所を選ぶと警告が出るので、その場合は縁を選び直してください。
> 一度取得したベース色が「自動」ボタンで上書きされることはありません。

### 6.2 露出（Exposure）

| スライダー | 範囲 |
|---|---|
| Exposure | −5.0 〜 +5.0 EV |
| Brightness / Contrast | −100 〜 +100 |
| Lights / Darks | −100 〜 +100（中間調の明部・暗部） |
| Whites / Blacks | −100 〜 +100（白点・黒点） |
| Clarity | −100 〜 +100（明瞭度） |
| Dehaze | −100 〜 +100（かすみ除去） |

### 6.3 フィルムラボ（Film Lab）

フィルム風の仕上げをまとめたセクションです。

- **Lab Glow** — ハイライトの滲み（0〜100）
- **Lab Fade** — 褪色（0〜100）
- **Soft Highs / White Clip** — ハイライトのなだらかな丸めと白のクリップ点
- **Soft Lows / Black Clip** — シャドウのなだらかな丸めと黒のクリップ点

### 6.4 カラーバランス（Color Balance）

タブで対象ゾーンを切り替えます。

- **WB** — 全体の色かぶり補正。色温度・ティント・Red⇄Cyan。**スポイトで取得**を使い、
  グレーまたは白であるべき場所をクリックすると1回でほぼ合います
- **Mid / High / Shadow** — 輝度ゾーンごとの色補正。**適用範囲を表示**でマスクを確認でき、
  **範囲**スライダーで効く幅を変えられます
- **輝度を維持** — 色を動かしても明るさを保ちます

### 6.5 カラー（Color）

Saturation / Vibrance（自然な彩度）/ Hue、および R・G・B ブースト。
このセクション上部の **カラー / モノクロ** 切り替えでモノクロ化もできます。

### 6.6 HSL / カラーミキサー

赤・オレンジ・イエロー・グリーン・アクア・ブルー・パープル・マゼンタの8色相帯ごとに、
色相・彩度・明るさを個別調整します。

### 6.7 RGB チャンネル

暗部／中間／明部の3ゾーンそれぞれに R/G/B のティントを加えます（プライマリー風のコントロール）。

### 6.8 カラーグレーディング

シャドウ／中間調／ハイライト／全体の4つのカラーホイールで色味を演出します。

### 6.9 カーブ（Curves）

RGB・R・G・B・輝度のトーンカーブ。

- 曲線上を**クリックで点を追加**、**ドラッグで移動**
- 点の**右クリックで削除**
- **リセット**で直線に戻す

### 6.10 ディテール（Detail）

Sharpness / Noise Reduction / Color NR（いずれも 0.00〜1.00）。

### 6.11 周辺光量（Vignette）

Amount（−100〜+100）と Feather（0.00〜1.00）。トリミング後の中心を基準に掛かります。

### 6.12 白枠 / EXIF 表記・書き出し EXIF

→ [9. 白枠と EXIF 表記](#9-白枠と-exif-表記) を参照。

### スライダー共通の操作

- **数値をクリック**すると直接入力できます
- スライダー横の **◀ ▶** は押し続けると連続で動きます（速度は設定で変更可）
- 変更した項目は数値の色が変わるので、初期値から動かした場所がひと目で分かります

## 7. プリセット

### 適用する

右のプリセットパネルで、項目に**カーソルを合わせると本画像でライブプレビュー**、**クリックで適用**されます。
内蔵プリセットは **アンダー** / **適正** / **オーバー** の3種類です。

### 保存する

`⌘⇧P`、またはパネル下部の **保存** ボタンから、現在の編集をプリセットにできます。
名前・説明（任意）に加えて、**保存する項目**（反転・露出・カーブ・カラーバランスなど）を選べます。

### 管理する

メニュー **プリセット ▸ プリセットライブラリ…** から：

- 名前の変更・複製・削除
- **現在の編集で上書き**
- **すべて書き出し** — 全ユーザープリセットを1ファイルにバックアップ（アップデート前の保険に）
- **インポート** — 書き出したファイルから復元・追加（メニューの「プリセットを読み込む…」も同じ）

## 8. 複数選択と一括編集

フィルムストリップでの選択：

| 操作 | 結果 |
|---|---|
| クリック | 単独選択 |
| `⇧` + クリック | 範囲選択 |
| `⌘` + クリック | 選択の追加／解除 |

複数選択中は、ストリップ下部に「n 枚選択中」のバーが出て、そのまま
**貼り付け**（コピー済み編集の適用）と **プリセット**（選んで一括適用）が実行できます。

### 編集内容のコピー／貼り付け

1. コピー元を選び `⌘⇧C`（編集内容をコピー…）
2. ダイアログで**貼り付け時に適用する項目**を選ぶ
3. 貼り付け先を選んで `⌘⇧V`

「ロール全体に適用」「複数選択への貼り付け」「プリセットの一括適用」は、いずれも **`⌘Z` 一回でまとめて取り消せます**。

## 9. 白枠と EXIF 表記

調整パネルの **白枠 / EXIF 表記** セクションで、書き出す写真の外側に余白フチを付けられます。

### 枠

- **余白** — 幅（単位切り替え可）
- **縦横比** — SNS 向けの比率に合わせる
- **枠の色** / **角丸** / **影**

### EXIF キャプション

**EXIF を枠に印字** をオンにすると、枠の余白部分に撮影情報を印字できます。

- **項目** — カメラ / レンズ / 焦点距離 / 絞り / シャッター / フィルム / 撮影日 / ファイル名 / 作者
- **位置**・**改行**・**区切り**・**書体**・**太字**・**文字サイズ**・**文字の不透明度**・**文字色**
- **文字のぶん余白を広げる** — 上下配置のとき、文字が写真に重ならないよう余白を自動調整

**ロール全体に適用** ボタンで、同じ枠設定をロール内の全写真へ広げられます
（EXIF の文字は写真ごとの値で印字されます。`⌘Z` でまとめて取り消し可）。

### 書き出し EXIF

**書き出しに EXIF を含める** をオンにすると、出力画像にメタデータを書き込みます。
メーカー・カメラ・レンズ・焦点距離・絞り・シャッター・ISO・フィルム・作者・著作権を自分で指定でき、
**空欄はスキャン元の値をそのまま引き継ぎます**。撮影日時も「上書きする」から変更できます。

フィルム撮影では、スキャナが書いたカメラ名がそのまま残ってしまうことが多いので、
ここで実際のカメラ・レンズ・フィルムに書き換えておくと、白枠のキャプションにも反映されます。

## 10. 書き出し

### 1枚だけ書き出す

| 形式 | ショートカット |
|---|---|
| JPEG | `⌘E` |
| PNG（16bit） | メニュー 書き出し ▸ PNG で書き出し… |
| TIFF（16bit） | メニュー 書き出し ▸ TIFF (16-bit) で書き出し… |

ダイアログで**形式・サイズ・ファイル名・書き出し先**を指定します。
書き出し先を指定しない場合は保存ダイアログが開きます。同名ファイルがある場合は確認が入ります。

### 一括書き出し

`⌘⇧E`（メニュー 書き出し ▸ 一括書き出し…）。

- 複数選択中は**選択した枚数だけ**、選択していなければロール全体が対象
- 形式・サイズ・出力フォルダを指定して **書き出し開始**
- 進捗と、失敗した場合はその理由が表示されます
- 出力先に同名ファイルがある場合は、上書きするかどうかの確認が入ります

### サイズ

設定の **書き出しサイズ**（単体・一括の両方に適用）：

- **フル** — 元の解像度のまま
- **長辺** — 長辺を指定ピクセルに合わせる（**拡大はしません**）
- **％** — 元の解像度に対する比率で縮小

### 色空間

設定の **出力色域** が JPEG / PNG に適用されます。
**16-bit TIFF は設定に関わらず、常にリニア sRGB で書き出されます。**

## 11. 設定

`⌘,` で開きます。**一般** と **キーボード** の2タブ構成です。

### 一般

| 項目 | 内容 |
|---|---|
| 言語 | 日本語 / English。切り替えは即座に反映されます |
| UIサイズ ▸ 表示倍率 | 調整パネル・プリセット・フィルムストリップの文字とコントロールの大きさ |
| 色補正の初期モード | 新しく読み込んだ写真の「ネガ反転 ▸ 色補正」の初期状態（マニュアル / オート / オート（自動適用）） |
| 出力色域 | JPEG / PNG 書き出し時のカラースペース |
| 書き出しサイズ | フル / 長辺 / ％ |
| プレビュー操作 ▸ ズーム感度 | ピンチズームの効き |
| 調整パネル ▸ 長押しの移動速度 | スライダー横の ◀ ▶ を押し続けたときの速度 |
| レンダリング ▸ FPS上限 | プレビュー再描画レートの上限。低いと CPU/GPU 負荷が下がります |
| アップデート | 起動時の自動確認オン／オフ、今すぐ確認、現在のバージョン表示 |
| 応援する | GitHub Sponsors へのリンク |

> **色補正の初期モードについて**
> 「オート（自動適用）」でも、読み込み時に行われるのは**ベース色の推定とオレンジマスク除去まで**です。
> ホワイトバランスは **自動** ボタンを押したときだけ動きます。

### キーボード

ショートカットの割り当てを変更できます。行をクリックしてキーを記録、`Esc` でキャンセル。
他の操作と重複する組み合わせは警告されます。個別リセットと全リセットが可能です。

## 13. 編集内容の保存について

編集は**元画像を書き換えず**、写真と同じ場所に `写真名.拡張子.tfl.json` というサイドカーファイルとして自動保存されます。
（例: `frame01.tif` → `frame01.tif.tfl.json`）

- 保存は自動です。明示的に保存したいときは `⌘S`
- 同じフォルダに `frame01.tif` と `frame01.jpg` のような拡張子違いの同名ファイルがあっても、それぞれ別に保存されます
- **書き込みできない場所**（読み取り専用のディスクイメージ、SD カード、共有フォルダなど）にある写真は編集を保存できません。
  この場合はフォルダごとに一度だけ警告が出ます。**編集の前にローカルディスクへコピーしてください**

## 14. 困ったときは

**色が思ったように出ない**
まず「ネガ反転 ▸ 色補正」をマニュアルにして、フィルムの縁（コマの外の素通し部分）からベース色を取り直してください。
そのうえで、カラーバランスの WB スポイトでグレーであるべき場所をクリックすると整います。

**古い写真の見た目が変わった／「新しい現像方式に更新」と出る**
v0.2.7 で、かすみ除去・カーブ・自然な彩度・周辺光量の処理を修正しました。
**それ以前に編集した写真は、見た目が変わらないよう以前の方式のまま表示されます。**
新しい方式にしたい写真では、調整パネル上部のボタンから切り替えられます（`⌘Z` で戻せます）。

**自動トリミングが枠を見つけられない**
傾いたスキャンや、コマの縁のコントラストが淡いスキャンでは検出できないことがあります。手動で枠を合わせてください。

**プレビューが重い**
設定の **レンダリング ▸ FPS上限** を下げると負荷が軽くなります。

**アップデートを確認したい**
メニュー **TomsFilmLab ▸ アップデートを確認…**、または設定の **アップデート ▸ 今すぐ確認**。
